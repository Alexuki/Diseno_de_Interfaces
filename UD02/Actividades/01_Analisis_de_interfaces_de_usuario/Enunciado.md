# Desenvolvemento de Interfaces Web

## Análisis de interfaces web

Analiza una página web que utilices habitualmente para identificar los principales elementos que componen su interfaz de usuario.

Documenta tu análisis mediante una pequeña memoria donde, mediante capturas de pantalla, identifiques cada uno de los diferentes tipos de elementos presentes en el interfaz de la web.

Procura escoger un sitio web que no sea demasiado complejo a nivel estructural. Y no hagas trampa empleando "inspeccionar" para ver cómo está construida, intenta plantearte cómo la construirías tú.

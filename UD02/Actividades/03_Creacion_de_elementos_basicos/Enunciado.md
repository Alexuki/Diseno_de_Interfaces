# Diseño de Interfaces Web

## UD2 – Actividad 3: Creación de elementos básicos

### Actividad 1

**Crear una página web básica.** Crea una página web sencilla que incluya un botón. Al hacer clic sobre él, deberá mostrar un mensaje en la consola del navegador.

### Actividad 2

**Página web con múltiples botones.** Crea una página que tenga dos botones: uno con el texto *"Aceptar"* y otro con el texto *"Cancelar"*.

Al hacer clic en el botón *"Aceptar"*, deberá mostrarse el mensaje *"Aceptado"* en la consola. Al hacer clic en *"Cancelar"*, deberá mostrarse el mensaje *"Cancelado"*.

### Actividad 3

**Interfaz con campos de texto.** Crea una página web que incluya un campo de texto donde el usuario pueda escribir su nombre y un botón.

Al hacer clic en el botón, deberá mostrarse en la consola el nombre introducido por el usuario.

### Actividad 4

**Uso de etiquetas y campos de texto.** Crea una interfaz web que tenga dos campos de texto con sus correspondientes etiquetas:

- Nombre.
- Apellidos.

Incluye un botón *"Enviar"* que, al ser pulsado, muestre un saludo personalizado en la página utilizando el nombre completo introducido por el usuario.

### Actividad 5

**Uso de ventanas y mensajes.** Crea una página web con un botón que, al ser pulsado, solicite al usuario su edad mediante una ventana emergente. Posteriormente, deberá mostrarse un mensaje indicando la edad introducida por el usuario. Puedes utilizar las funciones de JavaScript que consideres adecuadas, como `prompt()` y `alert()`.

### Actividad 6

**Menú desplegable.** Crea una interfaz web que incluya un menú desplegable con varias opciones para seleccionar un color:

- Rojo.
- Verde.
- Azul.

Al seleccionar una opción y pulsar un botón, deberá mostrarse en la página el color seleccionado. Como mejora opcional, puedes modificar visualmente algún elemento de la página utilizando el color elegido.

### Actividad 7

**Campo de contraseña.** Crea una interfaz web que incluya:

- Un campo para introducir el nombre de usuario.
- Un campo de contraseña.
- Un botón *"Iniciar sesión"*.

Al pulsar el botón, deberá mostrarse en la consola la información introducida por el usuario. Aplica estilos CSS básicos para mejorar la apariencia y organización del formulario.

### Actividad 8

**Botones de opción.** Crea una interfaz web con un grupo de botones de opción que representen diferentes métodos de pago:

- Tarjeta de crédito.
- PayPal.
- Transferencia bancaria.

Incluye un botón *"Confirmar"* que, al ser pulsado, muestre en la página el método de pago seleccionado.

### Actividad 9

**Casillas de verificación.** Crea una interfaz web con varias casillas de verificación que representen diferentes ingredientes para una pizza:

- Queso extra.
- Pepperoni.
- Aceitunas.

Incluye un botón *"Ordenar"* que, al ser pulsado, muestre en la página los ingredientes seleccionados por el usuario.

### Actividad 10

**Barra de navegación y menú.** Crea una página web que incluya una barra de navegación en la parte superior. La barra deberá incluir, al menos, las siguientes opciones:

- Inicio.
- Productos.
- Contacto.

Al hacer clic sobre cada opción, deberá mostrarse un contenido diferente en la página sin necesidad de crear páginas HTML adicionales. Aplica estilos CSS para mejorar la apariencia de la barra de navegación y destacar la opción seleccionada.

### Actividad final

Por último, crea una página web que permita acceder a las diferentes actividades realizadas.

La página deberá incluir:

- Un elemento para seleccionar una actividad.
- Un botón para cargar o mostrar la actividad seleccionada.
- Una zona de contenido donde se muestre la interfaz correspondiente.

Puedes utilizar un menú desplegable, botones, tarjetas o cualquier otro componente que consideres adecuado.

La interfaz deberá estar organizada y utilizar:

- **HTML** para estructurar el contenido.
- **CSS** para aplicar estilos y organizar visualmente los elementos.
- **JavaScript** para gestionar la interacción con el usuario.
